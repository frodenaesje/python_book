# ISBN-10

## Exercise

An ISBN-10 code consists of 10 characters: nine digits followed by a
check character. The check character is calculated from the first nine
digits using this formula:

checksum = (d1*1 + d2*2 + d3*3 + d4*4 + d5*5 + d6*6 + d7*7 + d8*8 + d9*9) % 11

If the checksum is 10 the check character is 'X', otherwise it is the
digit itself.

Write a program that:
1. Reads the first nine digits as a string from the user
2. Calculates the checksum using a loop and `enumerate()`
3. Displays the complete 10-character ISBN-10 code

## Example run

```
Enter the first 9 digits of the ISBN-10: 020161622
ISBN-10: 0201616220

Enter the first 9 digits of the ISBN-10: 013468599
ISBN-10: 013468599X
```

## Topics

- `for` loop over a string
- `enumerate()` to get index and value together
- Weighted sum with a loop
- Special case handling

## Instructor notes

**Learning objectives covered:** enumerate, weighted sum, loop accumulation

**Why this exercise belongs in ch 5:** Without loops, this requires nine
separate variables (s1 through s9) - exactly the kind of repetitive code
loops eliminate. With enumerate(), the solution is clean and elegant.

**The key pattern:**
```python
for i, char in enumerate(digits):
    total += int(char) * (i + 1)
```

**Note on leading zeros:** The input should be read as a string, not an
integer, to preserve leading zeros.
