# Exercises — Even-Numbered Solutions

This folder contains exercises for all even-numbered problems in the textbook
*Programming in Python — Fundamentals* by Frode Næsje.

Each exercise includes:

- **Problem description** — the full exercise text in markdown format
- **Starter code** — a code template to begin from
- **Solution** — a complete worked solution

These resources are provided for self-study and are free to use for 
non-commercial and educational purposes under the repository license.
