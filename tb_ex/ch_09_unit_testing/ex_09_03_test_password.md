## Assessment criteria

| Criterion | Description | Weight (%) |
|---|---|---:|
| Valid passwords | Checks that a password satisfying all four requirements is accepted. | 20 |
| Missing character requirements | Checks missing uppercase, lowercase and digit requirements independently using passwords that satisfy the other requirements. | 30 |
| Length boundaries | Checks short passwords and both the seven- and eight-character boundaries with otherwise valid passwords. | 25 |
| Parametrized valid cases | Uses pytest.mark.parametrize to run the multiple-valid-password test separately for each of the four specified valid passwords. | 25 |
| **Total** | | **100%** |
